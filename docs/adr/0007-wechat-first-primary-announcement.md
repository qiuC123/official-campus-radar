# ADR 0007：主要公告采用微信优先、官网降级

状态：已由 ADR 0009 取代

日期：2026-09-01

招聘批次的主要公告依次采用：经 wechat-oa 回读并完成企业官方身份、原文和批次范围核验的微信公众号文章；具备稳定打开方式和完整字段证据的官方微信小程序通知；官网具体招聘公告；官网招聘项目说明页；对应批次的官方投递页。该顺序取代 ADR 0005 和 ADR 0006 中的“官网优先”，因为微信公众号通常更早、更集中地给出届次、启动时间和招聘项目边界，而官网或招聘系统继续更适合提供结构化岗位和投递入口。

## Consequences

- 官网公告可以先准入批次；同批次的合格微信公告后来进入时，招聘雷达把它升级为主要公告，原官网公告仍作为辅助证据保留。
- wechat-oa 只提供微信通用证据，不自行判断企业、招聘批次、岗位或投递渠道；招聘雷达确认同一批次后才允许切换主要公告。
- 微信搜索结果、转载文章、身份未核验文章、未完成人工确认的图片文字都不能获得微信优先级。
- 微信小程序必须同时具备已核验企业身份、稳定名称与页面路径，以及足以证明标题、招聘类型、招聘对象和当前可申请状态的完整证据，才能排在官网前；否则继续采用官网主要公告。
- 微信与当前主要公告对招聘类型、招聘对象或当前可申请状态的解释发生冲突时，批次转为待人工确认，不自动覆盖字段；确认后才采用选定来源恢复准入。
- 岗位、地点、岗位数量和投递入口仍优先来自企业官网、招聘系统或官方接口，微信优先不改变岗位采集职责。
