# ADR 0002：以招聘批次组织岗位，投递进度归属于岗位

状态：已接受

日期：2026-08-26

企业招聘接口通常返回一组岗位而不是一篇公告，同一招聘批次中的不同岗位也可能具有不同投递结果。项目决定将领域模型从 `RecruitmentNotice` / `NoticePosition` 完整重命名为 `RecruitmentBatch` / `RecruitmentPosition`，并把 `ApplicationProgress` 从招聘批次迁移到具体岗位；页面仍按招聘批次分组，以兼顾信息密度和岗位级准确性。

## Considered Options

- 保持批次级进度：改动最小，但无法表达同一批次投递多个岗位的情况。
- 每个岗位独立平铺：进度准确，但会让大批量岗位页面过长。
- 批次分组、岗位级进度：采用；数据准确，同时保留紧凑浏览体验。

## Consequences

旧迁移与历史报告保持不变；新迁移负责模型、字段和配置契约重命名。旧数据库如果存在无法唯一映射到单个岗位的批次级进度，迁移必须停止并要求人工处理，不能猜测或删除。
