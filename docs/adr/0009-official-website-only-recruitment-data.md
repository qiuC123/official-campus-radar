# ADR 0009：招聘数据只采用官网和官方招聘系统

状态：已接受

日期：2026-09-03

招聘雷达的公告、招聘批次、岗位和投递信息只采用已准入的企业官网、企业官方招聘系统或其公开接口。主要公告依次采用官网具体公告、官方招聘系统项目页，以及能够证明批次范围的官方招聘或投递页面；项目停止调用 `wechat-oa`，微信公众号和微信小程序不再参与候选补充、字段解释或正式数据准入。这个决定取代 ADR 0007 的微信优先路线，因为真实对照中搜索渠道能返回大量相关微信链接，却不能稳定得到当前、官方且可回读核验的目标文章，而现有正式公告和岗位已经全部由官网或官方 ATS 支撑。

## Consequences

- Exa 或 Codex 仍可在已知官网入口不足时发现官网和官方 ATS 候选，但搜索标题、摘要、排名和模型判断都不是证据；候选必须回读官方页面并通过来源准入。
- 微信发现和导入命令保持显式停用，不会启动 `wechat-oa`、微信 HTTP 回读或 Chrome。
- 历史微信公告、账号身份和迁移字段不做破坏性删除，但微信公告不能成为主要公告，已经绑定为微信主要公告的批次也不得进入正式或历史展示。
- 没有可核验官网或官方 ATS 批次页面的企业保持待核验，不再以微信文章补齐。
