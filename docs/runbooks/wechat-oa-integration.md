# wechat-oa 集成（已停用）

根据 ADR 0009，招聘雷达从 2026-09-03 起只采用已准入的企业官网、官方招聘系统或其公开接口，不再调用 `wechat-oa`，也不再发现、回读或导入微信公众号和微信小程序数据。

`discover_wechat_oa_announcements` 与 `import_wechat_oa_announcements` 仅作为兼容墓碑保留：任何调用都会直接返回停用错误，不加载客户端、不启动子进程，也不写数据库。

历史微信公告、账号身份和迁移字段暂时保留，避免破坏旧数据库兼容；它们不能成为主要公告，也不会进入正式或历史招聘页面。需要重新启用微信来源时，必须先新增 ADR、恢复独立测试和运行手册，并取得用户明确确认。
