# Phase 02 / 正式页面数据归一化 Cycle 01

日期：2026-08-27

状态：已完成

## 用户发现的问题

- 部分公司类型显示为 `private`、`foreign` 等内部代码。
- 多数校招来源只写“应届毕业生”，导致筛选“2027届”时被漏掉。
- 工作地点直接汇总城市，企业覆盖范围较大时形成很长的城市列表；省份筛选也无法命中对应城市。

## 修正

- 正式页面统一使用 Django 公司类型中文标签：民企、央国企、外资、中外合资、银行、事业单位、社会机构。
- 本期校园招聘中，来源写“应届毕业生”“校招”或未写届别时，页面按已确认口径显示并筛选为“2027届”；明确写“2026届”等年份的批次保持原值，实习批次显示“实习生”。数据库和字段证据仍保留来源原文。
- 新增城市到省级地区的归一化；列表地点按省级地区去重，超过 6 个时折叠为“另有 N 个省级地区”。海外、全国和远程保留为特殊标签，无法识别的地点在没有可信省份时保留原文。
- `city=广东` 等现有 URL 参数现在按省份匹配，能够命中深圳、广州、东莞等城市；展开岗位仍保留官网提供的具体城市。

## 验证

- Django 完整测试：398/398 通过。
- 开发工具测试：140/140 通过。
- 正式数据库浏览器检查：筛选“2027届”返回 19 个批次；公司类型为中文；顺丰地点摘要为“广东、四川、湖北”，博世为“江苏”；筛选“广东”能够返回相关批次。
- 没有修改数据库、来源原始证据或企业采集配置，也没有访问企业网站。
