## 架构判断

三家的当前架构现在可以分成两类：

1. **北森新版 Portal 家族：上汽大众、vivo。** 两家使用同路径、同 `Data` / `Count` 响应外壳和同页码正文结构，公共传输适配可以复用；租户筛选值、岗位字段和校招范围仍必须逐家验证。
2. **中国电信 Vue 定制站。** 网站栏目接口和岗位接口是两套 API。本次只证明栏目接口可匿名读取，不能把栏目树误认成岗位。

这比 Cycle 04 更清楚，但“架构清楚”不等于“来源稳定”：标题、地点、校招原值和分页必须在保存证据中同时成立。
