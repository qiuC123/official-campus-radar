## 匿名第二页判别

最后一次无 Cookie、无签名、禁重定向、禁环境代理请求使用：

- `pageIndex=2`
- `pageSize=11`
- 当前官网 `Origin/Referer`
- 浏览器公开的 `Accept/Content-Type`

返回 HTTP 200，但业务结果仍为：

```json
{"code": 500, "message": "服务器出错"}
```

这与用户浏览器能够翻页并不冲突：浏览器会话可能带有匿名会话状态或认证状态，但公开匿名请求没有同等能力。浏览器可见不等于无需会话即可批量抓取。
