# Phase 02 页面原型修正记录 / Cycle 07

状态：H1 后置修正完成，纳入 H2 候选

日期：2026-08-26

交互原型：`docs/prototypes/phase-02/index.html`

## 已确认决定

- 投递进度归属于招聘批次，每个批次只有一个由用户手动维护的状态。
- 系统不统计批次内投递了几个岗位，也不按“最远进展”等规则自动计算。
- 代表岗位只用于帮助用户了解招聘方向，不保存岗位级进度。

## H1 后置修正

- 表头“招聘公告”改为“批次官网”，链接文字改为“官方页”。
- 未提供截止时间时只显示“未说明”；“招满为止”只允许在来源明确提供该原文时使用。
- 代表岗位保留可点击样式，点击后在当前批次下展开全部岗位，不再是无响应按钮。
- 运维区域明确标注为仅管理员可见；正式 Django 页面同时在服务端限制人工更新权限。
- 延续已通过的高密度横向表格方向：桌面窄于表格最小宽度时使用明确的横向滚动，不自动隐藏已确认列。

## 验证项

- [ ] 批次进度筛选和手动保存使用同一批次级语义。
- [ ] 未知截止显示“未说明”。
- [ ] 代表岗位可以展开和收起全部岗位。
- [ ] 页面不再出现“招聘公告”作为批次名称。
- [ ] 非管理员看不到运维状态且不能调用人工更新。
