## Cycle 03 用户反馈

筛选区也采用参考站的紧凑布局：两行筛选字段，下面紧接查询、重置和蓝色数据汇总条。

## Cycle 04 设计

- 移除占空间较大的四张统计卡片和城市复选框组。
- 筛选字段依次为公司名称、公司类型、地点、招聘类型、招聘对象、岗位、投递进度和截止时间。
- 地点和岗位支持使用中文或英文逗号输入多个条件；地点输入 `-全国` 时排除带“全国”标签的结果。
- 截止时间提供 1 天内、3 天内、7 天内以及招满为止/未说明。
- 查询与重置后显示蓝色汇总条：今日、近三天、1 天内截止和 3 天内截止的企业数量。
- 所属行业继续在结果表展示，但不占用筛选区。
- Cycle 03 的高密度横向结果表保持不变。
