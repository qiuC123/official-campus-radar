## 本 Cycle 修复

- 新增 `--reprocess-rejected`：只允许 `manual` 且必须显式提供 `--source-id`；普通每日更新不能触发同内容重处理。
- 同一内容只有在上一个版本全部为拒绝、歧义或超范围事件时才允许重处理；旧 SourceVersion 和 PublicationEvent 均保留。
- 结构化 JSON、ATS JSON 和 Moka 来源优先采用已核验的批次招聘类型；普通 HTML 仍保留“招标/招商”等负面词优先的安全规则。
- JSON 岗位地点缺失时保留为“未说明”，证据原值写为 `[not-provided]`，不猜测城市、不丢弃岗位。
- 相同岗位键且内容完全一致时安全去重；相同键内容冲突时整次失败，不猜测保留哪一条。
- 批次地点展示只列前 6 个代表地点，其余显示“另有 N 个地点”；筛选仍使用完整地点集合，避免真实大批次把表格行无限撑高。
- 有发布拒绝的 UpdateRun 现在为 `partial_failure`，不再显示为完全成功。
- 理想汽车单页从 10 调整为 100；美团只请求实习类别。三家初始配置修正通过“暂停→复核→启用”追加 9 条审计事件。

中国联通原计划移除 `code=200` 成功条件。实际重试和三个最小诊断请求都得到 HTTP 200、业务 `code=500`、`message=服务器出错`，且 `data` 中没有 `jobList`。这证明成功条件仍然有效，因此随后又通过“暂停→复核→启用”追加 3 条审计事件恢复该安全闸。联通公开页面仍能显示 2704 个岗位，说明页面可用，但当前最简 JSON 请求不可稳定复现；本项目不使用运行时浏览器或第三方网页渲染结果绕过来源准入。
