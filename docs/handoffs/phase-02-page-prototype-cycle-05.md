## Cycle 05 设计

- 公司类型：央国企、民企、事业单位、银行、外企/合资、社会机构，多选内部使用 OR。
- 招聘类型：春招、秋招、秋招补录、秋招提前批、实习、春招补录，多选内部使用 OR。
- 投递进度保留七种状态，允许多选，内部使用 OR。
- 地点弹层列出 34 个省级地区，允许多选并硬性限制为最多 5 个；达到 5 个后，其余未选项禁用。
- 每个多选弹层都有取消和确定。取消不改变已应用条件；确定后更新按钮摘要，点击查询才刷新结果。
- 选择具体省份时，“全国”和“远程”岗位仍作为特殊范围参与匹配。
- 招聘对象继续单选，岗位关键词继续支持逗号分隔多个条件。
