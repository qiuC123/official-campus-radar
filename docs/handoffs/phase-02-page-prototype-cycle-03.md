## Cycle 02 用户反馈

结果区不要使用批次卡片，改为参考页面的高密度横向表格。

## Cycle 03 设计

- 一个招聘批次占一行。
- 固定展示公司名称、公司类型、所属行业、招聘类型、招聘对象、工作地点、代表岗位、投递进度、更新时间、投递截止、投递链接和招聘公告。
- 代表岗位集中在一个蓝色边框单元格中，最多显示 5 个名称，超出时只提示剩余数量。
- 公司类型、招聘类型和招聘对象使用紧凑色块；投递和公告使用独立按钮。
- 投递进度只保留一个批次行级下拉框，不按具体岗位拆分。
- 桌面端保持高密度；窄屏使用横向滚动，不强行压缩所有列。

## 待确认的领域含义

当前正式领域模型把投递进度归属于具体岗位，而参考表格只展示一个批次行级进度。本 Cycle 只验证视觉和交互，不修改数据库。H1 通过时还需确认：这个下拉框是正式的“批次投递进度”，还是只显示该批次多个岗位进度的概览。
