日期：2026-08-27

状态：已完成；6 家均未达到 H3 五项条件，新增稳定接入为 0，累计仍为 3/50

## 本 Cycle 的目标

复验 Cycle 02 归入北森和大易经典版的六家企业，判断同一平台家族的读取规则是否仍可复用：

- 北森：航空工业、上汽大众、广汽丰田。
- 大易经典版候选：vivo、中国电信、中国信通院。

本轮不做 T4 来源准入，不写数据库，不使用生产浏览器，也不为了改善结果重复失败请求。

## 访问纪律

- 六个冻结入口各请求一次，最简请求头、无 Cookie、不跟随跳转。
- 原始 HTML 只保存在系统临时目录供离线分析，仓库保存哈希和最多 5 条字段样本。
- 根据第一页离线识别出的确切链接，追加四次不同资源请求：航空工业租户根页，以及上汽大众、vivo、中国电信页面明确声明的入口脚本。
- 广汽丰田没有第二页证据，中国信通院首次连接超时；两者均未重试。
- 共执行 10 次网络请求：6 个入口 + 4 个不同的架构跟进资源。没有登录、表单提交、Cookie、签名计算或访问控制绕过。

## 关键结论

“同域名/同供应商”只能用于选择探测策略，不能直接当作可复用解析规则。Cycle 02 的 3 个北森成员实际上至少存在三种当前状态：失效入口、新版 Portal、经典服务端 HTML；原大易经典候选也出现了自有 SPA、Vue 定制站和连接失败。

因此，本轮没有把任何一家追认为可稳定接入，也没有把页面中的菜单、组件名或非岗位 API 写成岗位数据。
