## Cycle 01 用户反馈

- 公司类型应按企业属性划分为民企、国企、外企等；互联网/科技属于行业。
- 招聘对象需要按届次细分。2026 年展示 2024届至2028届，并另列实习生；“在校生”统一表达为“实习生”。
- 首页不用逐个岗位列出投递情况，只需概括展示一些代表岗位。

Cycle 01 文件和原型历史结论不改写，本文件记录修改后的独立 Cycle。

## Cycle 02 设计

- 公司类型：民企、国企、外企、其他。
- 所属行业：互联网/科技、金融、能源/电力、制造业、通信。
- 招聘对象：2024届、2025届、2026届、2027届、2028届、实习生。
- 每个批次最多展示 5 个代表岗位名称，超过时显示剩余数量。
- 首页删除岗位级投递进度筛选、进度下拉框和“求职进行中”统计，第四项统计改为“覆盖公司”。
- 代表岗位仍可参与岗位关键词和城市筛选，但首页不逐岗展开职责或列出投递入口。

## 领域边界

本 Cycle 只改变首页的信息呈现，不把已有的岗位级投递进度解释为公司级或批次级进度，也不修改数据库。H1 通过后，才同步 Django 预览页和页面数据契约。
